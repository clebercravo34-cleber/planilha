# NICO Premiação — PWA para GitHub Pages

## Arquivos
- `index.html`: aplicativo
- `manifest.webmanifest`: nome, ícone e configurações de instalação
- `service-worker.js`: cache básico para abrir o app novamente
- `icons/`: ícones 192×192 e 512×512

## Publicar no GitHub
1. Crie ou abra um repositório no GitHub.
2. Envie todos os arquivos e a pasta `icons` para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/(root)`, depois salve.
6. Aguarde a publicação e abra o endereço HTTPS do GitHub Pages.

## Instalar no Chrome Android
1. Abra o endereço publicado no Chrome (não abra o arquivo HTML local).
2. Aguarde a página carregar e, se necessário, atualize.
3. Abra o menu ⋮ e escolha **Instalar app** ou **Adicionar à tela inicial**.

Observação: o PWA precisa estar publicado em HTTPS para o service worker funcionar. A sincronização com Supabase depende da URL, chave, tabelas e permissões já configuradas no aplicativo. O cache do PWA não substitui o banco de dados.
